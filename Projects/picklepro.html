PicklePro

Swift • SwiftUI • SwiftData • MapKit • CoreLocation • Accelerate

About

Built a native iOS pickleball tracking app for logging singles and doubles matches, reviewing match history, analyzing player stats, and mapping saved court locations. The app combines local persistence, court-based match records, profile setup, score validation, and dashboard-style performance summaries in a clean SwiftUI interface.

What it includes
  • SwiftData model for storing match history, scores, player names, match type, winners, dates, and court locations
  • Singles and doubles match logging with team-based player fields and editable match records
  • Pickleball-specific validation for unique player names, non-negative scores, no ties, higher-score winner, and win-by-two logic
  • Profile setup for user name, preferred hand, skill level, home court, and singles or doubles preference
  • Stats dashboard with win rate, win/loss record, average points scored, points allowed, streaks, opponent records, and court records
  • MapKit court view that displays saved court pins and court-specific match summaries
  • CSV export, demo data loading, onboarding flow, and local preference storage through AppStorage
Result

Turned a basic match logger into a more complete mobile product with persistence, validation, analytics, profile personalization, mapping, and export functionality. The project demonstrates practical iOS development across SwiftUI state management, SwiftData storage, MapKit integration, and reusable domain logic.
