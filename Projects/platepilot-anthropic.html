PlatePilot AI Recipe Search

JavaScript • Anthropic API • Web Search • Ingredient Scaling

About

Built an AI-powered recipe search experience that uses the Anthropic API with web search to find recipe options from across the web, then lets the user choose a recipe and scale the ingredients to a target serving size. The app manages search results, selection flow, serving adjustments, and recipe rendering in a polished single-page interface.

What it includes
  • Recipe discovery powered by Anthropic with web search
  • Interactive flow for search, recipe selection, and serving-size adjustment
  • Automatic ingredient scaling based on selected servings
  • Result cards with source, timing, difficulty, and serving metadata
  • Single-page UI with loading states, error states, and reset controls
Tech Stack
JavaScript HTML CSS Anthropic API Web Search JSON Parsing Single-Page UI
