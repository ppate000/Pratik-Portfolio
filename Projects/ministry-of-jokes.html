Ministry of Jokes

Python • Flask • PostgreSQL • SQLAlchemy • React • Docker • REST API

About

Built a full-stack joke management platform with a Flask REST API, PostgreSQL database, SQLAlchemy models, authentication, ratings, search, pagination, analytics, and admin moderation. The project focuses on backend architecture, database relationships, protected routes, API design, Dockerized local development, and automated testing.

What it includes
  • Flask REST API with structured success and error responses
  • PostgreSQL database with users, jokes, ratings, relationships, indexes, and constraints
  • Authentication with hashed passwords and protected user sessions
  • Admin-only moderation routes for managing flagged or inappropriate jokes
  • Search, filtering, sorting, and pagination for database-backed joke browsing
  • Analytics endpoints using joins, grouping, and aggregation queries
  • Rating system with a unique constraint to prevent duplicate ratings from the same user
  • Docker Compose setup for the backend, frontend, PostgreSQL database, and local AI rating service
  • pytest test suite and GitHub Actions workflow for validation and continuous integration
