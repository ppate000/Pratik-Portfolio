Movie Rating Prediction

Python • pandas • scikit-learn • Machine Learning • Regression • Streamlit

About

Built a machine learning regression pipeline that predicts TMDB movie vote averages using structured movie metadata. The project loads and merges TMDB movie and credits datasets, engineers features from financial, release, cast, genre, director, and production-company data, compares multiple regression models, and saves evaluation outputs for model analysis and recruiter-facing presentation.

What it includes
  • End-to-end pandas pipeline for cleaning, merging, and preparing TMDB movie data
  • Feature engineering from budget, revenue, runtime, popularity, release date, genres, cast, director, and production companies
  • Model comparison across baseline, Linear Regression, Ridge, Lasso, Decision Tree, Random Forest, and Gradient Boosting models
  • GridSearchCV tuning and evaluation using RMSE, MAE, R², SSE, and cross-validation RMSE
  • Saved prediction outputs, largest-error analysis, feature importance files, and visualization charts
  • Optional Streamlit dashboard for entering movie metadata and generating live rating predictions
Result

The strongest tested model was a Random Forest Regressor, which reached a test RMSE of 0.6087 and improved RMSE by about 29% compared with the baseline mean predictor. The project also includes feature-importance and prediction-error analysis to explain model behavior and limitations.
