High’s Hardware Store Management System

Java • OOP • File I/O • ArrayList • LinkedHashMap • Command Processing

About

Built a Java-based hardware store management system using object-oriented design, file I/O, and data structures to manage inventory, staff records, command processing, and schedule generation. The application reads structured input files, processes inventory and staffing commands, updates output files, and includes scheduling logic to assign workers based on availability and hours worked.

What it includes
  • Inventory CRUD (add, update, remove, search)
  • Order tracking and customer records
  • Fast search via data structures
  • Persistent storage via MySQL
