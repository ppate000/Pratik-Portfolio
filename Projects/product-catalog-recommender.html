C++ Product Catalog and Recommendation System

C++ • OOP • STL • File I/O • Inventory Tracking • Recommendation Logic

About

Built a terminal-based C++ product catalog and recommendation system inspired by e-commerce platforms. The project manages products, users, ratings, inventory, search, and recommendations while storing data through local text files for persistence between runs.

What it includes
  • File-backed product database with add, update, delete, view, and search functionality
  • User management and product rating system for storing user-product preferences
  • Inventory tracking with quantity updates and low-stock visibility
  • Search by product name or category using case-insensitive matching
  • Average rating calculations to summarize product performance
  • Simple recommendation logic based on user-product ratings and similarity-style ranking
  • Structured object-oriented design using Product, User, Rating, and CatalogSystem classes
  • Local persistence through products, users, and ratings text files
Why it matters

This project shows practical C++ experience beyond basic syntax. It combines object-oriented programming, STL containers, file I/O, menu-driven application design, and recommendation logic in a project that is easy to demo and explain to recruiters.

How to run
  • Open the project folder in VS Code or Terminal
  • Compile with g++ using C++17
  • Run the generated catalog executable from the same folder as the text data files
  • Use the menu to view products, search by category/name, add ratings, update inventory, and generate recommendations
