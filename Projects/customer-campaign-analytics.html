About

Built a static marketing analytics dashboard that presents campaign, segment, and customer performance in a clean, portfolio-ready interface. Structured the project to simulate a real business reporting tool by combining SQL-style data modeling concepts with frontend rendering, making it easy to showcase analytical thinking, dashboard design, and web development skills in one project.

What it includes
  • Dashboard-style summaries for campaign, customer, and segment performance
  • JavaScript-driven rendering of preloaded analytics data for an interactive feel without a backend
  • Business-focused reporting layout designed to communicate insights clearly and professionally
  • Static site structure that can be deployed easily on GitHub Pages
  • Project framing that blends software engineering, SQL logic, and analytics presentation
