Customer Campaign Analytics

Static analytics dashboard that presents campaign, segment, and customer performance through a portfolio-ready reporting interface.

HTML CSS JavaScript SQL Dashboard Design

Overview

This project is a portfolio-style analytics dashboard built as a static site. It displays campaign, segment, and customer insights using preloaded data, making it easy to deploy on GitHub Pages without needing a backend server.

What it demonstrates

Analytics presentation
Organizes marketing performance metrics into a clean dashboard format with tables, summaries, and trend views.
Frontend data rendering
Uses JavaScript to render preloaded analytics data dynamically so the interface still feels interactive without a backend.
Portfolio-ready deployment
Structured as a fully static project that can be hosted directly on GitHub Pages using plain HTML, CSS, and JavaScript.
Business relevance
Shows how software and data can be combined to communicate campaign results, customer value, and segment performance clearly.

Key features

  • Dashboard-style summaries for campaign and customer performance
  • Static deployment with no backend requirement
  • Interactive filtering and rendering with JavaScript
  • Clean, professional interface designed for portfolio presentation
